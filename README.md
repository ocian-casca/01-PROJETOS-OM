# 01-PROJETOS-OM

Projeto de desenvolvimento web criado para colocar em prática a construção de um site para a OM Construtora.

## Objetivo

Desenvolver a interface de um site institucional, trabalhando estrutura de páginas, organização visual e recursos de front-end.

## O que estou praticando

- Estrutura HTML
- CSS e organização de estilos
- Desenvolvimento de interfaces
- Organização de arquivos
- Versionamento com Git e GitHub

## Sobre o projeto

Este repositório faz parte da minha trajetória de estudos e desenvolvimento de projetos reais.

A ideia aqui é registrar a evolução do projeto, mantendo também a história do aprendizado.

**Status:** projeto de estudo/desenvolvimento.
